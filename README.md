# 🏃 AI-Powered Temple Run Game

An interactive endless-runner game developed with the assistance of **Kimi AI**, exploring how Generative AI can support the development of engaging games, interactive applications, and real-time game logic.

## ✨ Features

* 🏃 Player running and movement
* 🎯 Obstacle detection and avoidance
* 🪙 Coin collection system
* 💥 Collision detection
* ❤️ Player life/health system
* 📈 Increasing score and distance
* ⚡ Power-ups and rewards
* 🔄 Continuous gameplay
* 🎨 Interactive and engaging user interface
* 📱 Responsive game design
* 🤖 AI-assisted development using Kimi AI

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* Generative AI
* Kimi AI

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder.
3. Open the main HTML file in your browser.
4. Start the game and begin running! 🏃
5. Avoid obstacles, collect coins, and try to achieve the highest score.

## 🧠 AI-Assisted Development

Kimi AI was used as a development assistant throughout the project.

The experiment helped explore how Generative AI can assist with:

* Project planning
* Game design and development
* Player movement and controls
* Obstacle and collision logic
* Score and coin systems
* Debugging
* User-interface development
* Improving the overall gaming experience

## 🎯 Objective

The goal of this project was to combine **programming + Generative AI** to create an interactive Temple Run-style endless-running game while learning how AI-assisted development can accelerate the process of transforming an idea into a functional game.
